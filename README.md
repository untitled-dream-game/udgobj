# udgObj

**udgObj** is a *personal*, lightweight library for loading Wavefront .obj model files and using them.

## Features
- [x] Geometry vertices
- [x] Face elements
- [ ] Texture & normal vertices
- [ ] Line elements
- [ ] Materials

## Usage

Including the 2 files located in `src` is all that's needed to use udgObj.

## Building

The CMake build system is used for compiling this project. A minimum version of 3.13.5 is needed, but, otherwise, building should be fairly standard.
